# County dossiers

One file per Kentucky county we write about. Each is the evidence base for that county's page,
assembled before the page is written, per `docs/local-content-standards.md`.

**Nothing in a dossier is publishable until it is verified and dated.** These were compiled by
web search from an environment where direct page fetching was blocked, so every figure is
snippet-sourced. Confidence is marked on each item, conflicts are flagged rather than resolved,
and each dossier ends with a pull list of what only Austin can confirm.

## Workflow

1. **Research draft** (this stage). Search-sourced, confidence-rated, conflicts flagged.
2. **Verification pass.** Austin works the pull list: CMS files, phone calls, local knowledge.
   Every confirmed fact gets a source and a date. Conflicts get resolved to one number.
3. **Write.** The page is built from the verified dossier only. Minimum bar in
   `docs/local-content-standards.md`: 5+ Tier 1 facts, 1+ phone-verified fact, 1 experience
   paragraph, local help contacts, under 40% body similarity to sibling county pages.
4. **Annual refresh.** Every September, before AEP, when the new CMS landscape files land.

## The three files that unlock every county

Named precisely so they can be found on cms.gov:

1. **CY2026 MA and Part D Landscape file** (released 26 Sept 2025), plan counts per county.
   Diff against CY2025 to name exactly which plans left a county this year.
2. **MA State/County Penetration** (monthly, Abridged), the county's MA penetration percentage.
3. **Monthly Enrollment by Contract/Plan/State/County**: join H-numbers to parent organizations
   for county-level carrier market share.

## Standing cautions

- **Never fabricate a local detail.** One resident noticing kills the credibility the page
  exists to build.
- **Practices and systems, never individual physicians** as recommendations.
- **Plan counts and network status are factual content; named-plan benefits are marketing** that
  can require carrier approval and CMS filing. Stay on the factual side.
- **Do not cite our own site as a source.** A "47 plans in Fayette County" figure was found
  circulating whose only origin was bluegrassmedicarehelp.com. Re-verify from CMS.
